> My cat walked across my keyboard during a Zoom call, typed 'asdfgh', and my boss replied, 'Great point, let's do that.'

## Run

```sh
python3 main.py
```

The program validates the line (exactly one line, 1–200 characters, no leading/trailing whitespace), prints it, writes it to `/output/entry.txt`, and verifies the round-trip content matches.
