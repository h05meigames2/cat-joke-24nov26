Entry for the [make.fun bounty "The One-Line Cat Joke That Lands"](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262) — one original cat joke, one line, under 200 characters.

## The joke

> My cat shoved my phone off the table, watched it hit the floor, then looked at me like I'd dropped it.

## How it works

`main.py` writes the joke — and nothing else — to `/output/entry.txt`, where the competition's judge reads it. It also prints the joke to stdout. The program:

- keeps the joke to a single line under 200 characters (checked before writing),
- creates `/output` if it does not exist,
- needs no network, no API key and no input.

## Run it

```sh
python3 main.py
```
